# Changelog

## [0.1.2]

- Add translucent text highlights and edge marks for figure regions.
- Add a host-supplied evidence preview that works with hover, keyboard, and touch.

## [0.1.1]

- Register the package's documentation and skill as SciTeX Dev providers.
- Add Sphinx documentation for integrating the installed browser component.

## [0.1.0]

- Package the provider previously shipped by SciTeX Live Paper as a standalone component.
- Add a synchronized feed for PDF regions, unanchored entries, and host actions.
- Distribute the JavaScript, CSS, and TypeScript declarations together through PyPI.
