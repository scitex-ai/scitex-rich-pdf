# SciTeX Rich PDF

Rich PDF is the SciTeX browser component for PDF regions, comments, and a
synchronized feed. A host application supplies document access, feed content,
and actions. The SciTeX SDK supplies PDF rendering and coordinate transforms.
Live Paper supplies scientific content and actions through those ports.
